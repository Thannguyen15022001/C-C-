1. Class basis
- In class default access modifier is "private"
- In struct and union default access modifier is "public"
Example:
struct Vector
{
    int x;
    int y;
    int z;
};
// are equivalent to
class Vector
{
public:
    int x;
    int y;
    int z;
};

2. Inheritances
- Default inheritances in class is "private" but in struct is "public"
- It's even possible to have a class derive from a struct (or vice versa). Default inheritances is controlled by chird.
Example:
    Class A inheritance Struct B -> default private
    Struct B inheritance Class A -> default public
- (Public) interitance was frequently said to model an "IS-A" relationship.
Note: public inheritance should only be used when/if an instance of the derived class can be substituted for an instance of the base class under any possible circumstance (and still make sense)
