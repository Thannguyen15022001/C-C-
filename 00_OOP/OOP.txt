1. What is OOP?
    - Object Oriented Programming is a software design and development method basing on class and Object architecture

2. What is advantage of OOP?
    - Reuseability
    - Maintenance
    - Modularity

3. Object - Instance
    - Object is an software entity which includes attributes and method.
    Example:
    Person      ->  abtraction ->  Object name: Person
                                    attributes: name, occupation
                                    Method: printInfo, setNewJob
    - A particular object is called an Instance.

4. Class 
    - Class which is a bluaprint or prototye defines all common attributes and methods for objects which are have the same type.
    - Class is essentially an abtraction data type
    - A object is a specific Instance of a class

5. Attribute - Method
    - Attribute is data used to describe properties (variables) of a object.
    - Method are behaviors which object can do. Each method have ability to effect attribute of object.
Note: In C++, Attribute also is called Member data and Method is called Member function.

6. Message
    - Message is a request an object to invoke a method.
    - A message consist of:
        + Object receiving message.
        + Method used to process message.
        + Parameter contenting necessary information for method.

7. Encapsulation
    - Encapsulation conceals the functional details of a class from object that send message to it.
    Example:
        Person just only communite with ATM machine by message. ATM machine is a top secret. So I can not reveal something more.
        Person can't know:
            + How much money are there in this machine?
            + How does the machine operate?
            + Can I get money without PIN?

8. Inheritance
    - Inheritance means that a class can inherit or re-use attributes and methods that are defined in other class.
    - Super-class <- Sub-class:
        + Super-class is a class having some attributes or methods that one or more classes inherit.
        + Sub-class is a class having some inherited attributes or methods from Subper-class and adding its own attributes or method.
Note: In C++ programming, Super-class is called Base class and Sub-class is calles Derived class

9. Polymorphism
    - Polymorphism is the ability of objects belonging to different data types to respond to method calls of methods of the same name, each one
    according to an appropriate type-specific behavior.

10. Class can have these kinds of members:
    - Member function, Bit-fields, Classes, Member data, Friend, Structure, Enumerations, Type name, Union
Note: Friend are include in the preceding list because they are contained in the class declaration. However, they are not true class members,
     because they are not in the scope of the class

    - Access control prevents you from using objects in ways they were not intended to be used
        + Private: Class members declared as private can be used only by member function and friends (class or functions) of the class
    - Protected: Class member declared as Protected can be used by member function and friends (class or function) of the class. Additionally, they can be used by class
        derived from the class.
    - Public: Class member declare as public can be used by any function
Note: Access control is equally applicable to all names: member functions, member data, nested classes, and enumerators

11. Inline member function 
    - The inline specifiers instruct the compiler to insert a copy of the function body into each place the function is called.

Note: Using inline function will have larger memory and fast execution. (Bởi vì không tốn thời gian gọi hàm)

12. Contructor
    - Contructor is a specific function used to initialize member data. It is called automationally when object is created
    - A member function with the same name as its class is a constructor function. Contructors cannot return calues.
    - Constructors are called at the point an object is created. Objects are created as:
        + Global (file - scope or externally linked) object
        + Local object, within a function or smaller anclosing block.
        + Dynamic object using the new operator. The new operator allocates an object on the program heap or "free store"
        + Base class sub-object of a class. Creating objects of derived class type causes the base class component to be created.
Note: If there is no constructor declare in class, compiler will create the default constructor without argument. An integer data will be initialized 0 and a pointer member data
        will be initialized as NULL pointer.

13. Destructor
    - "Destructor" functions are the inverse of constructor functions. It is called automationally when object are destroyed (deallocated)
    - A class can define many constructor, however a class has only one destructor

14. This pointer
    - In C++, this (also called self or Me in other language) is a keyword that is used in instance methods to refer to the object on which they are working
Note: Static member functions do not have a this pointer.

15. Scope resolution operator ::
    - You can tell the compiler to use the Global identifier rather than the local identifir by prefixing the identifier with :: the scope resolution operator
    Syntax: identifier can be a variables or a function
        + ::identifier
        + class-name::identifier
        + namespace::identifier
    - It is necessary to use the :: in some cases:
        + Call member function of base class.
        + Access a identifier which is concealed(che giau) by the local identifier

16. Member initialization list
    - The member initialization list is the preferred method to initialize the members of a class.
    - Member initialization list is used to initialize:
        + Contant member data
        + Reference member data
        + Member object
        + Base class
